# The Art of Telling

A ten-session creative writing salon in short story, poetry, and memoir, led by James F. Mulhern.

**Live site:** [https://art-of-telling.com](https://art-of-telling.com)

## About this repository

This repository is the source for the Art of Telling salon course website.
The site is a static HTML/CSS site with no build step — every file in the repo
root serves directly.

Companion course sites (each maintained as its own repo):

- [The 2601 Salon](https://salon.silvercurrentpress.com/) — full course catalog
- [Because There Wasn't Time](https://companion.art-of-telling.com) — the companion course
- [The Mulhern Library — Short Stories](https://shortstories.silvercurrentpress.com/)
- [Publishing Poetry](https://publishingpoetry.silvercurrentpress.com/)
- [Submitting Short Stories](https://submittingshortstories.silvercurrentpress.com/)
- [Submitting Memoirs](https://submittingmemoirs.silvercurrentpress.com/)
